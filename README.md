# Professeur Moustapha : Parcours France (v1.1)

Patch for the existing EGF game "Professeur Moustapha : Parcours France", which had been created by hand without an EGF editor and was not fully compliant with the EGF specifications. The game looks and plays exactly as before. The corrections affect internal elements only. This version of the game is now fully compliant with the EGF specifications.

This game is released under the [Creative Commons Attribution 4.0 International (CC BY 4.0) license](https://creativecommons.org/licenses/by/4.0/deed).

The game EGF is embeded using Embedded EGF 1.1 Reader.
